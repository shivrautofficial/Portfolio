# Shiv Raut Portfolio

The website lives in [`engineer-portfolio/`](./engineer-portfolio/). It is a React, TypeScript, and Vite portfolio covering Shiv's education, verified project contributions, cybersecurity training, skills, and interests in AI and robotics.

## Run locally

```bash
cd engineer-portfolio
npm ci
npm run dev
```

Build and preview the production version with:

```bash
cd engineer-portfolio
npm run build
npm run preview
```

See [`engineer-portfolio/README.md`](./engineer-portfolio/README.md) for profile editing, photo setup, and Vercel deployment instructions. In Vercel, set the project **Root Directory** to `engineer-portfolio`.
